# Android Native

## Manifest
- Internet permission enabled
- Main activity exported as launcher activity
- Cleartext traffic allowed for local development APIs

## Gradle
- Kotlin DSL build files
- Java 17 compatibility
- FlutterFire Google services plugin applied in the app module

## Kotlin
- `android/app/src/main/kotlin/com/example/mindset/MainActivity.kt` is the Flutter activity entrypoint.

## Important Notes
- The app is configured for the default application ID `com.example.mindset`.
- Release signing currently uses debug signing config.
