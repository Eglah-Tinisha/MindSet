# Widget Documentation

## Common Widgets
- `AppScaffold`: standard `Scaffold` with `SafeArea`
- `WellnessCard`: consistent card container
- `IconBox`: icon tile used for metric and feature visuals
- `PageTitle`: page heading + optional subtitle
- `SectionHeader`: heading row with optional action
- `AppTextField`: decorated form field wrapper
- `MoodBadge`: small chip showing a mood label and icon
- `BrandMark`: app logo/icon mark
- `AuthFormShell`: shared auth page scaffold
- `StatTile`: dashboard metric tile

## Journal Widgets
- `JournalEntryCard`: compact saved entry preview
- `MoodSelector`: selectable mood chips
- `VoiceRecorderCard`: transcript input panel for voice-based reflections
- `ReflectionResultCard`: full analysis output with confidence, summary, valence, and tags
- `PatternSummaryCard`: derived history summary

## Insight Widgets
- `EmotionProgressRow`: labeled percentage bar
- `InsightCard`: pattern explanation card
- `PromptCard`: reflective prompt card
- `ReportMetricRow`: key/value row in reports
- `ReportSectionCard`: report narrative section

## Settings Widgets
- `PrivacyNotice`: explanatory privacy callout
- `SettingsSwitchTile`: labeled switch row
- `PrivacySignalTile`: optional checkbox-style signal row
- `SettingsActionTile`: tappable action row
