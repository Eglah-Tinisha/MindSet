# Configuration

## Flutter
- `pubspec.yaml` defines package metadata and dependencies.
- `analysis_options.yaml` enables `flutter_lints`.

## Firebase
- `firebase.json` points Firestore rules to `firestore.rules`.
- `lib/firebase_options.dart` contains platform-specific Firebase config generated by FlutterFire.
- `android/app/google-services.json` is present for Android.

## Android
- `android/settings.gradle.kts`
- `android/build.gradle.kts`
- `android/app/build.gradle.kts`
- `android/app/src/main/AndroidManifest.xml`

## Python
- `understanding_ai/requirements_api.txt`
- `understanding_ai/api.py` has runtime configuration and CORS policy.
- `understanding_ai/bert_train.py` has training constants at the top.
- `understanding_ai/bert_predict.py` has inference constants and model path configuration.
