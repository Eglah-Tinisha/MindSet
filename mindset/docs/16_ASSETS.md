# Assets

## Flutter Assets
- No custom Flutter asset bundle is declared in `pubspec.yaml`.
- The UI relies on Material icons and generated platform icons.

## Platform Icons
- Android mipmaps under `android/app/src/main/res/mipmap-*`
- iOS app icon set under `ios/Runner/Assets.xcassets/AppIcon.appiconset`
- macOS app icon set under `macos/Runner/Assets.xcassets/AppIcon.appiconset`
